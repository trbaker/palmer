Reading the spectra

Scaled viewHorizontal position represents wavelength from 380 to 780 nm. Visible line colors are approximate wavelength colors.
Poster-style viewEach line is drawn with equal visual width and spacing, to resemble a reference chart rather than a quantitative wavelength axis.
Neutral line heightsThese previews do not imply measured relative intensity. Line height is a visual aid, not calibrated intensity.
Species matterAtomic spectra depend on the atom/ion, excitation conditions, and whether lines are observed or Ritz-calculated.
Scientific reference: NIST Atomic Spectra Database (ASD) [physics.nist.gov], Standard Reference Database 78, version 5.12 (content updated November 2024). For complete line lists, select an element and use the NIST query link in its detail panel. Preview lines are a curated educational subset for selected elements; other elements are linked to NIST rather than being assigned invented spectra. Element masses and common reference values are rounded teaching values; unavailable values are shown as not available. Verify critical measurements against primary references.
